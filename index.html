Rekayasa Perangkat Lunak

Saya Menempuh pendidikan di SMK Negeri 2 Mojokerto dengan mengambil konsentrasi keahlian Rekayasa Perangkat Lunak (RPL). Selama masa pendidikan, saya mempelajari dasar-dasar pemrograman, pengembangan aplikasi berbasis web, pengelolaan basis data, serta perancangan antarmuka pengguna. Pembelajaran dilaksanakan melalui kegiatan teori dan praktik di laboratorium komputer, serta proyek pengembangan aplikasi untuk mengasah keterampilan teknis, kreativitas, dan kemampuan pemecahan masalah.
