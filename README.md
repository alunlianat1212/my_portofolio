# Personal Portfolio — Sunshine Yellow

Buka `index.html` di browser (atau jalankan `npx serve` di folder ini).

## Ganti konten
- Teks: edit langsung di `index.html`.
- Foto (nama file harus sama; jika belum ada, placeholder tampil otomatis):
  - `profile.jpg`, `id-card.jpg`, `education.jpg`
  - `experience-1.jpg`, `experience-1b.jpg`
- Daftar/nama sertifikat: array `certs` di `script.js`.
- CV: taruh file di `cv.html`.
- Warna: variabel di bagian `:root` pada `style.css`.
- Email tujuan form: cari `mailto:` di `script.js`.
